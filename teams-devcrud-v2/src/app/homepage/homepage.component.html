Software Engineering Specialization

Frontend Development

Learn how modern user interfaces are built using HTML, CSS, JavaScript, TypeScript and Angular. Create responsive and interactive web applications with reusable components.

Backend Development

Build server-side applications, REST APIs and database-driven systems. Learn how clients and servers communicate and how data is processed and stored.

Software Engineering

Practice version control, testing, teamwork and clean code principles. Learn how software projects are designed, developed and maintained in a professional environment.

Semester Requirements

Students are expected to understand the fundamentals of JavaScript, TypeScript and Angular. During the semester they will create components, use data binding, services, routing and communicate with backend APIs.

Students will design and implement REST API endpoints, work with databases and learn the basic principles of authentication, authorization and server-side application architecture.

Students are required to work on practical development tasks using Git and GitHub. The project should demonstrate proper source control, structured code and communication between frontend and backend components.

Technologies

Modern client-side applications built with TypeScript and component-based frameworks.

Backend

Development Workflow

1. Planning

Define requirements, application features and the overall architecture.

2. Development

Implement frontend components, backend services and database operations.

3. Testing

Test individual components and verify that different parts of the application work together correctly.

4. Deployment

Deploy the completed application and make it available to users.

Practice-Oriented Development

The goal of the specialization is not only to understand software development concepts, but also to apply them in real projects.

Students work with frontend and backend technologies, build complete web applications, use version control and learn how different layers of a modern software system work together.
